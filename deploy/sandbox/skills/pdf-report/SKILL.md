# pdf-report

    python /buddy/skills/pdf-report/pdf_report.py report.md output/Report.pdf --title "Rent in Miraflores"

Markdown it understands: `#`/`##`/`###` headings, paragraphs, `- ` bullets, `**bold**`,
tables written as `| a | b |` lines, and images `![caption](chart.png)` (e.g. a chart you made).
